# Space Message

Interactive 7-page space-themed message website built with React + Vite + Framer Motion.

## Pages

1. Opening
2. Personal message
3. NASA ticket
4. Tap-all-planets mini game
5. Rocket launch
6. Animated character scene
7. Ending

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy to Vercel

1. Push this project to a GitHub repository.
2. Import the repository into Vercel.
3. Framework preset: Vite.
4. Build command: `npm run build`
5. Output directory: `dist`

No environment variables are required.

## Assets

Provided PNG assets are stored in `public/assets/`.

## Sound

The current build uses lightweight Web Audio UI tones so the site works without shipping copyrighted audio. The `public/sounds/` folder is reserved for custom sound files if desired later.
